How to Engineer Sub-50ms Real-Time ML Routing Systems from First Principles

Most tutorials stop at model.fit() and model.predict(). Real-world streaming AI systems fail on noisy GPS telemetry, cold-start sparsity, right-skewed uncertainty, and Python pointer overhead. Below are the 5 core mathematical & systems primitives powering delhi-transit-planner—interactive, runnable in your browser, and distillable into 15-line Python patterns for any future system.

Module 01 • Systems Architecture & Memory Layout

Binary Serialization, CSR Arrays & Numba @njit

Protobuf Polars + Zstd CSR Float32 Numba @njit

1. The Big Picture & Notebook Flowchart

Decoupled 4-Layer

Intuition: Never mix slow network/ML inference with hot path queries. Split every streaming engine into four decoupled layers: (1) Binary Ingestion, (2) Vectorized State Extraction, (3) Precomputed Tensor + Decay, and (4) Contiguous Memory Decision Kernel.

Why CSR + @njit? A Python list[list[int]] scatters tiny 28-byte PyObject structs across RAM, causing CPU cache misses on every edge hop. Packing variable-length routes into two flat contiguous arrays (offsets + flat_data) lets Numba compile tight loops into LLVM machine code with hardware prefetching.

Where else to reuse: Orderbook L2 snapshots, ragged RAG token batches, AdTech user-click graphs, molecular adjacency lists, or fleet telemetry pipelines.

3. Reusable 15-Line Python Pattern (CSR + Numba @njit)

import numpy as np
from numba import njit

def pack_csr(lists: list[list[int]], weights: list[list[float]]):
    offsets = np.zeros(len(lists) + 1, dtype=np.int32)
    offsets[1:] = np.cumsum([len(x) for x in lists])
    flat_edges = np.concatenate(lists).astype(np.int32)
    flat_w = np.concatenate(weights).astype(np.float32)
    return offsets, flat_edges, flat_w

@njit(fastmath=True)
def scan_csr(offsets, edges, weights, best):
    for r in range(len(offsets) - 1):
        acc = np.float32(0.0)
        for k in range(offsets[r], offsets[r + 1]):  # contiguous L1 scan
            acc += weights[k]
            if acc < best[edges[k]]: best[edges[k]] = acc

Module 02 • Spatial Geometry & Signal Cleaning

1D Linear Referencing & Isotonic Regression (PAVA)

Dot-Product Projection 75m Off-Route Gate Monotonic PAVA

1. The Big Picture & Notebook Flowchart

2D → 1D Signal
$$t_{\text{proj}} = \operatorname{clip}\!\left(\frac{\overrightarrow{AP} \cdot \overrightarrow{AB}}{\|\overrightarrow{AB}\|^2},\; 0,\; 1\right), \qquad \hat{d}_{\text{mono}} = \arg\min_{z_1 \le \dots \le z_m} \sum_{i=1}^m (z_i - d_i)^2$$

Intuition: Roads curve in 2D (lat, lon), making Euclidean distance between stops useless. By projecting GPS onto a polyline into 1D cumulative meters $d_m$, every stop and vehicle becomes a single scalar!

Why PAVA? Urban GPS multipath makes buses appear to jump backward by 40m at intersections, creating negative travel times! Pool-Adjacent-Violators (IsotonicRegression) merges violating pairs into their weighted average in $O(m)$ time, guaranteeing monotonic progress before interpolating departure times at canonical stop positions.

Where else to reuse: Drone/robot path-following error, calibration curves (Platt/isotonic probability calibration), wearable altimeter cleaning, conveyor-belt sensor alignment.

3. Reusable 15-Line Python Pattern (1D Projection + PAVA)

import numpy as np
from sklearn.isotonic import IsotonicRegression

def project_to_polyline(px, py, poly_x, poly_y, poly_s):
    ax, ay, bx, by = poly_x[:-1], poly_y[:-1], poly_x[1:], poly_y[1:]
    abx, aby = bx - ax, by - ay
    L2 = np.maximum(1e-9, abx**2 + aby**2)
    t = np.clip(((px - ax) * abx + (py - ay) * aby) / L2, 0.0, 1.0)
    dist = np.hypot(px - (ax + t * abx), py - (ay + t * aby))
    i = int(np.argmin(dist))
    return float(poly_s[i] + t[i] * np.sqrt(L2[i])), float(dist[i])

def clean_and_interpolate_stops(t_pings, d_pings, d_stops):
    d_mono = IsotonicRegression(increasing=True).fit_transform(t_pings, d_pings)
    u_d, idx = np.unique(d_mono, return_index=True)  # collapse dwell flat spots
    return np.interp(d_stops, u_d, t_pings[idx])     # exact stop timestamps

Module 03 • Applied ML Beyond Toy Tutorials

Empirical Bayes Shrinkage, Gamma-LightGBM & Ratio Quantile Loss

LOO Shrinkage Gamma Deviance Pinball α=0.85

1. The Big Picture & Notebook Flowchart

Zero Leakage ML
$$w_{-i} = \frac{n - 1}{(n - 1) + k}, \qquad \hat{\theta}_{\text{EB},-i} = w_{-i}\bar{y}_{-i} + (1 - w_{-i}) m_{\text{global}}, \qquad q_{85} = \hat{\mu} \cdot \max\!\left(1.03,\; r_{\text{shrunk},85}\right)$$

Intuition: Across 15,130 corridors × 96 time bins, most cells have $n = 0, 1, 2$ observations! Raw averages overfit wildly; Leave-One-Out Empirical Bayes smoothly pulls low-sample corridors toward a diurnal spatial prior $m_{\text{global}}$, and excludes row $i$ itself ($n_{\text{loo}} = n - 1$) so trees never memorize target noise.

Why Ratio Quantile? Training a separate quantile tree on $y$ directly often produces q85 < mu (quantile crossing)! Instead, we train Head 2 on the dimensionless ratio $r_i = y_i / \mu_{\text{oof}, i}$ with pinball loss $\alpha = 0.85$, shrink $r_{85}$ toward $r_{\text{global}, 85}$, and clamp $\ge 1.03$.

Where else to reuse: Delivery ETAs, API p95 latency forecasting, insurance claim severity, hospital LOS, SaaS customer spend modeling.

import numpy as np, lightgbm as lgb

def oof_eb_encode(keys, y, m_prior, k=5.0):
    cnt, tot = {}, {}
    for g, v in zip(keys, y): cnt[g], tot[g] = cnt.get(g, 0) + 1, tot.get(g, 0.0) + v
    out = np.empty(len(y))
    for i, (g, v, mp) in enumerate(zip(keys, y, m_prior)):
        n_loo = cnt[g] - 1
        w = n_loo / (n_loo + k) if n_loo > 0 else 0.0
        out[i] = w * ((tot[g] - v) / max(1, n_loo)) + (1.0 - w) * mp
    return out

Module 04 • Real-Time Online Learning & O(1) Prefix Sums

Offline Tensors + Ratio Decay & Correlated Prefix Variance

Zero Live .predict() Ratio Decay γ_0 e^-dt/τ O(1) Correlated V(i→j)

1. The Big Picture & Notebook Flowchart

< 3 ms Serving
$$\hat{y}(t) = \mu(t)\Big(1 + \gamma_0 e^{-\Delta t / \tau}(q_0 - 1)\Big), \qquad V(i \to j) = (1 - \rho)(S_2[j] - S_2[i]) + \rho(S_1[j] - S_1[i])^2$$

Intuition 1 (Offline Tensors): A static road graph has finite corridors ($15{,}130$) and finite 15-min slots ($96 \times 2$). Precomputing all $2.9\text{M}$ cells into an 11 MB float32 tensor replaces 15,000 LightGBM tree traversals per query with a single NumPy slice + exponential ratio decay!

Intuition 2 (Correlated Prefix Variance): Summing segment variances independently ($\rho=0$) drastically underestimates trip uncertainty because traffic jams span consecutive blocks! Storing two prefix sums—$S_1[k] = \sum \sigma_e$ and $S_2[k] = \sum \sigma_e^2$—lets us compute exact correlated variance for any sub-path $i \to j$ in just two array lookups!

Where else to reuse: Streaming SLA tail risk over microservices spans, financial portfolio covariance over rolling windows, supply-chain multi-hop lead-time buffers.

3. Reusable 15-Line Python Pattern (O(1) Prefix Range Stats)

import math, numpy as np

class PrefixRouteStats:
    def __init__(self, mu_e: np.ndarray, sig_e: np.ndarray, rho: float = 0.60):
        self.rho = rho
        self.Tcum = np.concatenate([[0.0], np.cumsum(mu_e)])
        self.S1 = np.concatenate([[0.0], np.cumsum(sig_e)])
        self.S2 = np.concatenate([[0.0], np.cumsum(sig_e ** 2)])

    def query(self, i: int, j: int, kappa: float = 1.036):
        mu = float(self.Tcum[j] - self.Tcum[i])
        ds1, ds2 = float(self.S1[j] - self.S1[i]), float(self.S2[j] - self.S2[i])
        V = (1.0 - self.rho) * ds2 + self.rho * (ds1 ** 2)
        s2 = math.log(1.0 + V / max(1.0, mu ** 2))
        q85 = mu * max(1.03, math.exp(-0.5 * s2 + kappa * math.sqrt(s2)))
        return mu, V, q85

Module 05 • Round-Based DP & Stochastic Arrival Calculus

RAPTOR, Chriqui-Robillard Common Lines & Live + Poisson Wait

Rounds k=1,2,3 Attractive Set A(u,v) Hybrid Live + Poisson

1. The Big Picture & Notebook Flowchart

Pareto Optimal
$$T_r < W_A + \bar{T}_A, \qquad E[W_A] = \frac{1 - e^{-\Lambda \Delta^*}}{\Lambda}, \qquad \Lambda = \sum_{r \in A_{\text{live}}}\frac{1-\text{cov}_r}{EH_r} + \sum_{r \in A_{\text{untracked}}}\frac{1}{EW_r}$$

Intuition 1 (Chriqui-Robillard): At a corridor stop, you don't wait 20 minutes for Route 425 if Route 449 arrives first and gets you there almost as fast—yet you skip a slow scenic route whose extra ride time exceeds the expected wait saved! Sorting routes by $T_r$ and stopping when $T_r \ge W_A + \bar{T}_A$ solves this exactly.

Intuition 2 (Live + Untracked Fleet): If 60% of buses have GPS and the nearest tracked bus arrives in $\Delta^* = 12$ mins, an untracked bus might still show up sooner! Modeling untracked arrivals as a Poisson hazard $\Lambda$ yields the closed-form truncated exponential expectation $E[W_A] = (1 - e^{-\Lambda\Delta^*}) / \Lambda$.

Where else to reuse: Multi-region LLM/GPU request hedging, parallel queue routing with partial telemetry, logistics carrier pooling.

3. Reusable 15-Line Python Pattern (Common Lines + Hybrid Wait)

import math

def chriqui_robillard_select(routes_t_ew):
    lam, wt_t, chosen = 0.0, 0.0, []
    for r, T_r, EW_r in sorted(routes_t_ew, key=lambda x: x[1]):
        if chosen and T_r >= (1.0 / lam) + (wt_t / lam):
            break
        w_r = 1.0 / max(60.0, EW_r)
        lam += w_r; wt_t += w_r * T_r; chosen.append((r, T_r, EW_r))
    return chosen, 1.0 / lam, wt_t / lam

def hybrid_live_poisson_wait(delta_star, sigma_b, lam_untracked):
    if delta_star is None or delta_star > 1500.0:
        return 1.0 / max(1e-4, lam_untracked)
    x = lam_untracked * delta_star
    return delta_star * (1.0 - 0.5 * x) if x < 1e-5 else (1.0 - math.exp(-x)) / lam_untracked
